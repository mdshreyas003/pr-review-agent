01System

One loop, five parts

A pull request arrives, is claimed once, reviewed, and remembered — a human decides what leaves the loop. Hover Trigger for detail.

02Loop

Claimed once, resumable anywhere

The same commit can only be claimed once — webhook or poller, whichever gets there first. A dead worker resumes from the last checkpoint instead of restarting; a cancelled task stops between stages, never mid-model-call. Hover a node for detail.

03Agents Engine

A protocol, not a framework

A review is an ordered list of named nodes; the engine that runs them is an interchangeable detail. Native is a few dozen lines of asyncio — the right size for a five-way fan-out with one checkpoint between phases. Hover a node for detail.

04Specialists

Five opinions, one verdict

Five specialists reason in parallel over the same grounded context; the gate — not the model — decides who sees it first. Hover a node for detail.

05Memory Strategy

Chunk once, retrieve twice

Indexing is structural, not fixed-width — chunks split on definitions so a function and its signature stay together, and content hashes make a re-index of an unchanged file free. Retrieval fuses vector and keyword rankings by reciprocal rank, so an embedding that smoothed away an identifier is still caught by the other lane. Hover a node for detail.

06Architecture Explorer

Four layers, nine components

Zoomed out, it's four layers: ingress decides a review is needed, compute runs it, data is the one place state actually lives, and the surface is where a human sees and directs all of it. Hover a node for detail.
